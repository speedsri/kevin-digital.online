The full architecture, explained end to end

Inbound flow, outbound flow, sender mapping and database schema — everything that makes DT Platform4 reliable, transparent and auditable.

Complete system diagram

Capture · Store · Manage · Reply · Audit

01 · INBOUND

Incoming Message Flow

The customer's message hits the Meta WhatsApp Cloud API, is delivered to our PHP webhook, and passes signature verification, request validation and duplicate prevention before it's saved.

  • Create/update customer & conversation
  • Insert message with channel = CUSTOMER
  • Insert initial status event
02 · OUTBOUND

Outgoing Reply Flow

Whether a reply comes from the Dashboard, Mattermost, or an automation, it's always written to the database first, then sent through the WhatsApp Cloud API — "write first, then send."

  • Dashboard replies tagged to logged-in user
  • Mattermost replies mapped to real names
  • Automated replies tagged channel = AUTO
03 · ATTRIBUTION

Mattermost Sender Mapping

The mattermost_user_map table links each Mattermost username to a real staff user ID and display name — so reporting is always accurate and readable.

  • Proper staff attribution
  • Raw usernames always preserved
  • New users mapped easily via admin
Database schema

A normalized schema built for a permanent audit trail

users

Staff accounts — id, name, email, password_hash, role, timestamps.

customers

WhatsApp contacts — id, phone (unique), name, profile picture, timestamps.

conversations

One thread per customer — id, customer_id, status, last_message_at.

messages

Every message — content, media, channel, sender, whatsapp_message_id.

message_status_events

Full delivery lifecycle — sent, delivered, read, failed, with raw response.

mattermost_user_map

Maps Mattermost usernames to internal user IDs and display names.

Security & reliability

Every layer is verified before it's trusted

  • Meta signature verification for all webhooks
  • Prepared statements (SQL injection protection)
  • Strong password hashing
  • Secure session management & login
  • CSRF protection on all forms
  • Input validation & sanitization
  • Complete audit trail, write-first principle
